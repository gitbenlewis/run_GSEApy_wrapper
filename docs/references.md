# Reference acquisition, routing and QC

1. **Safe entrypoint:** `python config/download_gseapy_gmt_files.py --manifest declaration.json --output /path/to/new-snapshot` requires an explicit JSON declaration. The previous no-argument bulk downloader is intentionally disabled. The [example declaration](../config/reference_manifest.example.json) is incomplete and deliberately cannot execute: species/source evidence remains unknown. It is a schema example, not a verified reference inventory. Add every requested collection explicitly; nothing is silently dropped.

2. **Declaration schema 1:** Required top-level fields are `schema_version: 1`, `target_species` (`human` or `mouse`) and a nonempty `resources` list. Each resource has a unique filename-safe `id`, `provider` (`enrichr` or `msigdb`), explicit `collection`, `identifier_species`, `identifier_species_evidence_url`, and `source_url`. URLs must use HTTP(S); they are recorded caller declarations, not automatically fetched or verified. `source_study_species`, `release`, `license` and `license_url` may be unknown/null where the provider allows. Enrichr requires `endpoint_organism` separately: an endpoint name does not establish identifier species. MSigDB requires the approved `2025.1.Hs` or `2025.1.Mm` release corresponding to declared identifier species. The approved MGI request uses 2024; no other release refresh is included.

3. **Routing:** Unknown/mixed identifier species blocks the entire requested snapshot before downloads. Native target-species GMT files are copied byte-for-byte into `routed/<target>/<id>.gmt`; opposite-species sets are converted. Source downloads remain separately under `source/<id>/<collection>.gmt`. No species inference uses library names, symbol capitalization, source-study organism or Enrichr endpoints. The public low-level converter signatures are unchanged; callers using them directly remain responsible for establishing source species. The high-level acquisition entrypoint enforces declarations.

4. **Mapping inputs:** `mappings.human_to_mouse` and/or `mappings.mouse_to_human` supply CSV paths relative to the declaration file (absolute paths also work). Conversion requires `gene_name`, the scalar target column (`mouse_gene_name` or `human_gene_name`) and its complete relationship column (`mouse_gene_names_all` or `human_gene_names_all`). For custom converter target-column arguments, the complete column name is derived by appending `s_all`; there is no scalar fallback. Complete lists are comma-separated, with surrounding whitespace trimmed. Literal symbol text such as `NA` is retained. Missing source identifiers fail with CSV line numbers.

5. **Approved ortholog policy:** Collapse repeated equivalent source relationships; reject differing complete target sets or distinct nonblank scalar targets for the same source, even if the input GMT never uses that source. A scalar target absent from its complete list also raises. List order alone does not constitute a conflict. Retain only sources with exactly one target and targets with exactly one source across the complete map. Exclude both one-to-many and many-to-one relationships. These are uniqueness rules within the supplied mapping, not proof of evolutionary one-to-one orthology. Checked-in mappings currently fail this validation; they were not automatically repaired or replaced.

6. **Conversion losses:** Unmapped and ambiguity-excluded source genes are dropped and separately counted. Retained targets are deduplicated in first-occurrence order. Terms becoming empty are omitted and reported; no coverage threshold is imposed. Native sets preserve their original members, including duplicates. A converted collection may be empty after the policy, with zero terms and explicit QC rather than silent collection omission. Invalid GMT rows and duplicate term IDs fail validation.

7. **QC and hashes:** Conversion writes `<output>.qc.json` with per-term and total source, mapped, excluded, unmapped, deduplicated and output counts; empty-term counts; and mapping-policy counts. Gene counts are occurrences unless labeled `unique`; per-term unique source counts are not summed as a library-wide unique count. `mapped_count` is before target deduplication; `deduplicated_count` is the difference. Many-to-one targets are excluded before conversion, so remaining deduplication normally reflects repeated source members. Mapping one-to-many/many-to-one counts can overlap; excluded count is their union. Native resources receive per-term/library source/output QC in the manifest. Source GMT, mapping CSV (when used), and output GMT SHA-256 hashes are recorded.

8. **Provenance manifest:** Each published snapshot contains `manifest.json` with schema/routing-policy versions, requested target species, provider collection/release, endpoint, declared species evidence, source-study organism when known, relative source/output paths, hashes, QC, and installed GSEApy/pandas/NumPy versions. Mapping source URL and release remain null because they are unknown. License fields remain null unless declared; null never means unrestricted reuse. `acquisition_time` is deliberately null to make equivalent acquisitions deterministic, not a claim about historical retrieval time. Two acquisitions of identical source bytes and settings in the same software environment produce identical manifest content despite different staging/output roots.

9. **Publication:** The complete request is preflighted before network acquisition. Downloads and conversion occur in a hidden sibling staging directory. Every declared resource must produce exactly its expected GMT, with valid nonempty source records. The manifest is written only after every request succeeds, then the directory is renamed atomically to a new destination on the same filesystem. Existing destinations, including symlinks, are refused. Download, conversion, or publication exceptions remove staging; tests also cover `KeyboardInterrupt`. A hard kill may leave an unpublished hidden staging directory, but cannot expose a partial final snapshot. Concurrent publishers to the same destination are unsupported. Existing checked-in reference directories are never rewritten by this entrypoint.

10. **Scope and licensing:** Direct low-level download/conversion functions retain their output-path APIs and are not multi-file transactions; use the snapshot CLI for atomic publication. MSigDB and Enrichr download helpers now reject absent requested collections instead of silently omitting them. See [data licenses](../DATA_LICENSES.md) for source-specific terms and unresolved mapping/Enrichr evidence. Software licensing does not grant data redistribution rights. No live downloads, reference replacement, mapping repairs, installs or redistribution occurred during implementation; tests use synthetic mappings and mocked provider calls.
