# Dotplot selection and display

1. **Measure selection:** An explicit GSEApy `column` wins over `pvalue_col`. Otherwise `pvalue_col` determines the probability measure. Nominal aliases are `pval`, `P-value`, and `NOM p-val`; adjusted aliases are `fdr`, `FDR q-val`, and `Adjusted P-value`. Missing cells can be filled from another alias in the same family, including across concatenated tables. The requested column takes precedence for nonmissing cells; no nominal/adjusted substitution occurs. Numeric strings are accepted. Rows missing the selected measure cannot pass its cutoff. Invalid strings and probabilities outside `[0,1]` raise. Explicit nonprobability columns such as `NES` retain GSEApy's native handling.

2. **Selection:** The wrapper applies `cutoff` to original probabilities (`<=`, including reported zeros), then selects the smallest `top_term` values. For categorical x columns, selection is per x group, as in GSEApy. Equal probabilities retain input order at the selection boundary. Explicit `ordered_terms_list` filters full IDs before selection and supplies the y order unless an explicit `y_order` is present. It also supplies the default top-term count. Defaults remain cutoff 1 and top 15.

3. **Zero display:** Only after selection, zeros receive a finite plotting replacement. With `n_perm_4_zero_pavlues=N`, this is `min(1/N, smallest positive selected probability / 2)`; if selected probabilities are all zero it is `1/N`. With `None`, it is half the smallest positive selected probability, and all-zero selections raise. The scope is the entire selected rendering table, including all x groups. A half-minimum floor that underflows to zero raises clearly. The parameter's existing spelling and default 10000 are retained. This display convention does not change statistical values or claim a revised probability estimate.

4. **Rendering:** The wrapper computes `-log10` directly on a rendering copy. This avoids GSEApy's clipping of subnormal probabilities and prevents its cutoff from filtering display replacements. Plot colorbar labels explicitly identify the requested measure as `-log10(<measure>)`. The original probability column remains unchanged in the plotting table, and caller DataFrames are unchanged. This intentionally changes zero color values and labels relative to older plots; small positive probabilities stay below reported zeros in significance display when both are selected. Selection is independent of the floor.

5. **Labels:** Full category IDs reach GSEApy. `term_label_col` chooses y ahead of the forwarded `y` argument, and the chosen column is now forwarded correctly. `term_label_char_limit` shortens rendered tick text only. Two full IDs sharing a shortened label remain two rows/dots; shortened labels can therefore look identical. Use a longer limit or no limit to distinguish them visually. Explicit order lists contain full IDs.

6. **Saving and return values:** With `ofname`, shortening is applied before the figure is saved and the function returns `None`, matching GSEApy. Otherwise it returns the Axes. Saved-file format and figure arguments remain forwarded through GSEApy/Matplotlib. Both single- and multiple-table entrypoints use the same preparation. Lollipop behavior is unchanged.

7. **Verification:** Focused tests cover opposing nominal/FDR rankings, explicit precedence, mixed aliases and missing cells, numeric strings, raw zero cutoffs, all-zero plots, subnormal values, display floors, custom y, colliding shortened labels, and the saved-figure return contract. Synthetic examples are diagnostic fixtures, not biological results. GSEApy still controls scatter sizing, layout, clustering and color normalization; those internals are outside this correction.
